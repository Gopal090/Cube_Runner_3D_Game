# 🧊 Cube Runner 3D

A fast-paced 3D endless runner. Steer your cube through obstacles, survive as long as you can and set a new high score.

## Gameplay

- The cube moves forward automatically and speeds up over time
- Steer left and right to dodge obstacles
- Colliding with an obstacle ends the run
- Your score increases with distance survived

## Controls

| Key | Action |
|-----|--------|
| A / ← | Move left |
| D / → | Move right |
